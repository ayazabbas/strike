# 世界杯倍数预测

Strike 倍数预测是围绕世界杯活动设计的结构化精确结果预测产品，使用固定倍率。

线上入口：[strike.fun/world-cup-multiplier-predictions](https://strike.fun/world-cup-multiplier-predictions)。

## 工作方式

每个倍数预测事件都会配置一组结果，例如精确比赛结果字段或其他清晰定义的世界杯结果。每个可选结果都有一个指定倍率。

提交预测时：

1. 选择一个开放中的倍数预测事件。
2. 选择一个或多个结果。
3. 查看组合倍率和潜在赔付。
4. 输入 USDT 预测金额。
5. 确认钱包流程：先授权 USDT，再提交到金库。

只有在**所有已选择结果全部正确**时，预测才会获胜。任意一个所选结果错误，该倍数预测就不会获胜。

## 组合倍率

如果你在同一个事件中选择多个结果，界面会把这些结果的倍率相乘，并在提交前展示组合倍率。

示例：

- 结果 A：2×
- 结果 B：3×
- 组合倍率：6×
- 预测金额：10 USDT
- 如果所有所选结果都正确，潜在赔付：60 USDT

只有通过 API 和金库覆盖检查并被接受的预测，才对应报价中显示的赔付。

## 预测奖池与奖励兜底池

倍数预测使用两个池子：

- **预测奖池** — 来自用户提交的预测金额。
- **奖励兜底池** — 用户可以贡献 USDT，赚取预测奖池剩余奖励，同时提供兜底覆盖。

如果没有预测获胜，或者获胜预测没有用完整个预测奖池，剩余预测奖池会按比例分配给奖励兜底池贡献者。

当前产品经济规则：

- 预测奖池剩余部分 100% 分配给奖励兜底池贡献者。
- 平台对剩余预测奖池保留 / 抽成为 0%。
- 该产品方向下，预测金额、获胜赔付和贡献者奖励费用为 0%。

## Earn：贡献到奖励兜底池

Earn 标签页允许用户通过金库向奖励兜底池贡献 USDT。

当预测奖池有剩余资金时，贡献者可能获得奖励。但当预测奖池不足以支付已接受预测的赔付时，奖励兜底池也可能被用于兜底覆盖。

这意味着贡献者存在下行风险。应用会在贡献或提交预测前显示风险与覆盖信息，而 API / 金库检查仍然是 accepted amounts、提款、领取、退款和结算状态的权威来源。

## 覆盖预检

在请求报价前，前端会估算当前奖励兜底池是否可以支持所选倍率和预测金额。

如果覆盖额度看起来不足，界面可能会显示降低后的最大预测金额。这只是客户端估算；API 报价和金库交易检查仍然是权威检查。

## 结算、领取和退款

事件结算后：

- 获胜预测可以领取符合规则的赔付。
- 被取消或退款的事件可能显示退款操作。
- 投资组合收据会显示倍数预测条目、状态、所选结果、预测金额、潜在赔付 / 退款、交易链接，以及可用时的领取 / 退款操作。

## 重要提示

- 倍数预测一旦提交即为最终状态。
- 精确结果规则很重要：所有选择的结果都必须正确才会获胜。
- 奖励兜底池贡献者可以获得奖励，但也承担兜底风险。
- 确认前，请始终检查事件、所选结果、组合倍率、预测金额、潜在赔付和钱包提示。
