# 交易指南

本指南介绍 STRIKE 订单簿市场以及 parimutuel 彩池市场的交易方式。

## 市场形式

STRIKE 提供两种主要交易体验：

- **订单簿市场** — 使用限价单、FBA 撮合，并支持到期前卖出头寸的活跃二元市场。
- **Parimutuel 彩池市场** — 面向 2–8 个结果的简单市场，用户买入某个结果池，并在结算后领取收益。

以下先介绍订单簿交易，再介绍彩池市场。

## 理解订单簿价格

Strike 中每个订单簿市场都有两个结果：**UP** 和 **DOWN**。仓位按每 lot **$0.01** 到 **$0.99** 的价格交易。

价格反映市场隐含概率：

| Price | Implied Probability |
|-------|-------------------|
| $0.10 | 10% chance |
| $0.25 | 25% chance |
| $0.50 | 50% chance |
| $0.75 | 75% chance |
| $0.99 | 99% chance |

例如，UP 价格为 $0.30，表示市场大致认为标的资产在到期时高于 strike price 的概率为 30%。如果你认为实际概率更高，这就是你的交易机会。

## UP vs DOWN

- **UP** -- 你认为资产价格在到期时会**高于** strike price。
- **DOWN** -- 你认为资产价格在到期时会**低于** strike price。

结算时一个方向会获胜。获胜订单簿仓位按完整结算价值赔付；失败仓位没有赔付。

## 下单

STRIKE 中的所有订单都是**限价单**。你需要选择：

1. **Side** -- UP 或 DOWN
2. **Price** -- 你愿意支付的最高价格（例如 $0.35）
3. **Amount** -- 你想买入的 lot 数量

你的订单会进入订单簿，并在下一个批次中尝试撮合。

## 批次如何工作

STRIKE 使用 **Frequent Batch Auctions** 实现公平的价格发现。流程如下：

1. 订单会进入由 keeper 清算的短批次。具体节奏会因市场和网络状况而变化。
2. 窗口结束后，该批次内的所有订单同时撮合。
3. 系统计算一个**清算价格**，该批次内所有成交都按同一价格执行。

这意味着没有人能因为速度更快而获得不公平优势。同一批次中的所有成交者都得到相同价格。

## 阅读订单簿

订单簿会显示每个价格档位上的休眠买单和卖单：

- **UP side** -- 买单（bid）在左侧，卖单（ask）在右侧。
- **DOWN side** -- 与 UP side 镜像对应。

最佳买价和最佳卖价之间的价差说明市场紧密程度。价差越窄，通常表示当前价格附近流动性越充足。

## 订单类型

### GTC (Good Till Cancelled)

订单会留在订单簿中，直到成交或被你取消。如果某个批次只成交了部分数量，剩余部分会自动滚入下一个批次。

### GTB (Good Till Batch)

订单只在当前批次有效。如果未成交，会自动过期，无需手动取消。适合你只想按当前价格尝试成交，而不想留下休眠订单的场景。

## 休眠订单

提交价格远离当前市场价格的订单通常不会立即成交，而是作为**休眠订单**留在订单簿中，等待市场向该价格移动。这些订单仍然有效，并会在清算价格到达其价格档位时参与批次撮合。

可以把休眠订单理解为持续报价：“如果价格到达 $0.15，我愿意买入 UP。”

## 卖出你的头寸

你不必等到市场结算。如果你持有 UP 或 DOWN 仓位，可以在到期前通过订单簿卖出。

这让你可以：

- **锁定利润**，当价格已经向有利方向移动时
- **控制亏损**，当你改变判断时
- **围绕价格变化主动交易**

## 在投资组合中管理头寸

你的**投资组合**页面会显示：

- **Open 订单** -- 等待成交的订单
- **Active positions** -- 你在实时市场中持有的仓位
- **Resolved 市场** -- 已结算且可领取收益的市场

## 领取收益

市场结算后：

1. 进入**投资组合**
2. 找到已结算市场
3. 点击 **Claim** 领取你的 USDT payout

如果你的方向获胜，利润等于获胜赔付减去你的入场成本和费用。

## 费用

STRIKE 对每笔交易收取固定 **0.20% 费用**（20 basis points）。费用由买卖双方平均分摊，买方 0.10%，卖方 0.10%。没有隐藏成本，也没有浮动费率。

## 交易 Parimutuel 彩池市场

Parimutuel 市场比订单簿市场更简单：

1. 打开一个 pool 市场。
2. 选择你认为会获胜的结果。
3. 输入你想买入的 USDT 数量。
4. 查看预计 payout 和隐含概率。
5. 提交买入。

这里没有限价单、休眠订单、GTB/GTC 选择，也没有卖单。你会持有 pool position，直到市场结算。

## 阅读彩池市场

每个结果都会显示：

- **Pool size** -- 当前支持该结果的 USDT 总量。
- **Implied probability** -- 基于资金池余额和曲线设置计算出的当前市场估计。
- **Projected payout** -- 如果该结果获胜，你本次买入预计可获得的收益。

随着其他用户买入任意结果，预计收益会动态变化。

## Pool 市场时间

Parimutuel 市场会同时显示：

- **交易 closes** -- 最后可买入该 pool 的时间。
- **结算 time** -- 结果被评估的时间。

这两个时间可以不同。例如，交易可以在比赛开始时关闭，而结算在比赛结束后发生。

## 领取 Pool 收益

pool 市场结算后：

1. 进入市场页面或投资组合。
2. 如果你的结果获胜，点击 **Claim** 领取 payout。
3. 如果市场被标记为无效，点击 **Refund** 取回本金。

失败结果不会获得 payout。
