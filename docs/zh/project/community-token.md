# 社区代币

## 概览

BNB degen 社区成员在 [flap.sh](https://flap.sh) 上为 Strike 创建了一个社区代币。我们希望清楚说明这个 token 是什么，以及它不是什么。

- **合约：** `0xdccc017b0f923cf3f3acdb535eb1019439717777`
- **flap.sh：** [https://FLAP.sh/bnb/0xdccc017b0f923cf3f3acdb535eb1019439717777](https://flap.sh/bnb/0xdccc017b0f923cf3f3acdb535eb1019439717777)

## 你应当了解的内容

**这不是官方 Strike token。**

Strike 没有发行 token。flap.sh 上的社区代币是社区成员发起的独立行动。它并非由 Strike 团队设计、部署或背书。锁定的 LP 及其交易费用与 Strike 协议运营相互独立。

我们感谢 BNB 社区的热情和支持。这反映了大家对我们正在构建的产品抱有能量和期待。

## 为什么该 Token 不能成为官方 Strike Token

即使暂且不讨论 Strike 未来是否会发行 token，也有一些具体原因使这个社区代币无法被采纳为官方 token。

**法律问题。** Strike 团队没有参与该 token 的创建或部署。事后采纳它会引发严重的法律和监管问题，涉及责任、证券分类和分配等方面。我们不能让项目处于这样的处境。

**Token 名称是固定的。** 该 token 名为 "Hackathon Runner-Up"，且名称无法更改。它不能代表项目，我们也无法围绕一个并非由我们选择、且无法修改的名称构建官方 token 叙事。

**我们没有参与 tokenomics 设计。** 供应量、分配与 allocation 均由非 Strike 团队的参与者决定。官方 token 需要谨慎设计这些参数，直接继承一套我们未参与制定的 tokenomics 并不可行。

**空投活动并不可行。** 该 token 的结构不适合面向我们的用户或社区设计有意义的空投活动。任何未来 token 分配都需要围绕明确目标从头设计。

## 我们对 Token 的立场

**Strike 当前没有发行官方 token 的计划。**

我们专注于将协议交付到主网。这是当前优先事项。未来如果真的就 token 作出任何决定，我们会通过官方渠道公布，并在此处记录。

## 关于未来计划的说明

如果 Strike 未来某个时候发行官方 token，我们承认社区代币持有者很早就支持了项目。我们会探索通过空投、迁移路径或其他机制对此予以认可。

**这不是承诺或保证。** 目前没有任何条款，也没有任何决定。我们只是想说明：我们看到了这份支持，也不会忘记。

## 持有者跟踪

我们已经在链上跟踪社区代币持有者地址、余额和持有时长。这些数据会被动记录，并会在未来如推出积分计划时纳入其中。

更早、更久的持有会在此类计划中得到体现。持有者无需采取任何操作，数据会自动从链上状态捕获。
