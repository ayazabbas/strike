## 你应当了解的内容

**`$STRIKE` 现在是 Strike 的官方平台代币。**

该代币最初由社区发起，而不是由 Strike 团队最初发行。这段历史依然重要。现在的变化是：Strike 正式采纳 `$STRIKE` 作为协议今后的平台代币。

Strike 会长期建设。正式采纳 `$STRIKE` 的目的，是让协议、产品和社区在平台成长过程中更加一致。
