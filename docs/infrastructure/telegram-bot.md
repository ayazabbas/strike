# Telegram Bot

Strike previously maintained a lightweight Telegram trading interface. The current public trading surface is the web app at [strike.fun](https://strike.fun).

Use the web app for current wallet connection, full orderbook trading, charts, portfolio actions, pool markets, World Cup markets, and multiplier prediction tickets.

If a Telegram bot is re-enabled, document its live commands, wallet model, and limitations from the current bot source before publishing this page in the docs navigation.
